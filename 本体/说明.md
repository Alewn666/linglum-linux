# Linglum —— 灵珑系统（纯 Linux 内核版）

**本目录 = 灵珑系统的 Linux 内核版。它的用途：就是一个操作系统。**

## 它是什么
一套可独立启动、可日常使用的操作系统：
- **内核**：Linux 7.3.0-rc7（aarch64，预编，USB/virtio/磁盘/显示驱动全内建）
- **用户态**：自研 init（PID 1）+ BusyBox 工具集（ls/cat/mount/dd/… 全套）
- **形态**：Live ISO 启动即用 —— 开机进「灵珑系统」，屏幕与串口各有一个 shell

和纯自研的 LoongOS 是**同一个灵珑系统的两条技术路线**（一个内核自研、一个用 Linux 内核），
各自都是独立的操作系统，互不替代。

## 附带能力：安装 LoongOS
这张 ISO 里同时内置了 `install-loongos`：Live 环境下敲一句，即可把**纯自研 LoongOS**
写进目标硬盘。这是"顺手带上的工具"，不是本系统的唯一用途。

```
UEFI → GRUB → Linux 7.3 → 灵珑 Live 环境（tty1 屏幕 + ttyAMA0 串口）
     ├─ 日常使用：shell 里跑任意 busybox 命令
     └─ 可选：install-loongos /dev/vda   （dd 写 MBR + ESP，含 BOOTAA64.EFI + kernel.elf）
              → 重启拔盘 → 固件直接加载 ESP → LoongOS
```

## 构建 / 验收
```sh
sh build.sh                 # NAS 上跑：内核→BusyBox→initramfs→ISO
python3 test_linglum_iso.py # 冒烟：横幅/shell/uname/fb0/安装器就位
python3 test_install_e2e.py # 端到端：Live 安装 LoongOS → 只挂硬盘重启 → 进 LoongOS
```

## 已知坑
- QEMU 必须显式 `-drive if=pflash,format=raw,file=/usr/share/AAVMF/AAVMF_CODE.fd`，
  不加载 AAVMF 固件时串口零输出（不是 ISO 坏）。
- GRUB 与内核 fbcon 都没有中文字形 → 菜单标题和 motd 用英文。
- `/bin/sh` 是 dash，**不支持 `{}` 花括号展开**（`mkdir rootfs/{bin,sbin}` 会造出字面量目录）。
- ISO 会被 libvirt 挂载时自动 chown 成 `libvirt-qemu`，属正常现象。
